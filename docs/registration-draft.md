# 앱 등록 입력 초안

상태: 입력 제안이며 외부 콘솔에서 생성하지 않았다. 이름과 고유 ID의 최종 확정 전이다.

## 어떤 앱을 만들고 싶나요?

사용자가 질문에 답하면 AI 무당 캐릭터가 답변을 바탕으로 고민과 감정을 추론하고, 점사 형식의 풀이와 조언을 제공하는 비게임 서비스입니다. 기본 점사 이후 광고 시청으로 추가 조언과 선택 풀이를, 인앱 결제로 상세 점사를 제공할 예정입니다. AI 생성 결과임을 안내하고 실제 예언이나 결과의 정확성을 보장하지 않습니다.

## 입력값 제안

- 앱 이름: `신통 AI점집` (후보이며 확정 전, 화면의 10자 제한 이내)
- appName: `sibyl` (현재 프로젝트 설정과 일치, 사용 가능 여부 미확인)
- 앱 유형: `비게임`

공유된 콘솔 화면에서 표시 이름은 나중에 수정 가능하지만 appName은 변경 불가라고 안내한다. 고유 ID의 실제 중복 여부와 대상 워크스페이스는 조회 전이다.

## MCP 확인

공식 문서는 `workspace_list`, `miniapp_list`, `miniapp_create`를 제공한다. 따라서 MCP 기반 신규 앱 생성은 지원한다. 로컬 CLI에서 apps-in-toss-console 등록·활성 상태는 확인했지만 현재 대화의 도구 목록에는 이 MCP가 노출되지 않아 실제 조회·생성은 실행하지 않았다.

MCP 도구가 제공되는 세션에서 대상 워크스페이스와 기존 앱을 조회하고, 확정된 이름·식별자로 생성할 수 있다. 앱 생성, 앱 정보 검토, 번들 검수, 출시 승인은 별개 단계다.
